Privacy Policy

Last updated: 23 July 2026

Relay is a small, self-hosted chat service. It is not a commercial product: there are no ads, no analytics, no trackers, and nothing is sold or shared with advertisers. This page explains, in plain terms, what the software actually stores and who can see it.

Who runs this service

This is a private instance of Relay, run on a server controlled by its operator. Your data lives on that server. If you have questions about your data, or want your account or content removed, contact the person who runs this instance — the site administrator.

What is stored

  • Account details — your username, email address, display name, and optional bio and pronouns. Your password is stored only as an Argon2 hash; the plain password is never saved.
  • Google sign-in — if you sign in with Google, basic profile information (email address and name) is received from Google to create and identify your account. No other provider is used.
  • Messages — the content of everything you post, including direct messages, along with timestamps, sender, reactions, mentions, edits, and thread relationships.
  • Files you upload — attachments and images, stored on the server's disk.
  • Presence — whether you are online, when you are typing, and any "away" status. This is shown live to other users and is not kept as long-term history.
  • Moderation records — when an administrator or channel operator performs a privileged action (kick, ban, granting operator status, deleting a channel), the action, who did it, who it affected, and a short note are recorded for accountability.

Messages are not end-to-end encrypted

Please read this one. Traffic between your browser and the server is encrypted with HTTPS, but messages are stored in the server's database as ordinary text. That means the operator of this server — and anyone with access to the database or its backups — is technically able to read any message, including direct messages. Treat Relay as private-ish, not as a secure messenger. Do not use it for information that would be harmful if read by the server's administrator.

File uploads are served from public links

Uploads are not access-controlled. Each uploaded file gets a hard-to-guess random address (for example /api/uploads/<random-id>). Anyone who has that link can open the file without logging in, whether or not they belong to the channel it was shared in. The link is not published or guessable, but it is the only thing protecting the file — so treat anything you upload as shareable.

Other details about uploads:

  • Photos have their location data removed. JPEG, PNG, and WebP images are re-encoded inside your browser before they are sent. That process discards embedded metadata, including EXIF GPS coordinates, so the original file with your location never leaves your device. If an image cannot be re-encoded, the upload is refused rather than sending the untouched original.
  • GIFs and documents are uploaded exactly as they are. They are not modified, so any metadata inside them — author names, location, editing history — is uploaded and served along with the file. Strip these yourself first if that matters to you.
  • Uploads are capped at 10 MB per file and 5 uploads per minute, and only images and common document formats are accepted.

Your IP address

Your IP address is used briefly to limit repeated failed sign-in attempts. It is held in a short-lived cache (about a minute) and is not attached to your profile or message history. As with any website, the server software may record ordinary request metadata in its logs.

Third parties

  • GIF search — searches are relayed through this server rather than sent from your browser, so Giphy does not receive your IP address when you search.
  • Images hosted elsewhere — when a message contains a Giphy or Imgur image, your browser loads that image directly from those services in order to display it. This reveals your IP address and browser details to them, exactly as visiting any web page containing their images would.
  • Google — only if you choose to sign in with Google.

There are no other third parties, and no advertising or analytics services of any kind.

What is kept in your browser

Relay does not use tracking cookies. It stores two things locally in your browser: your sign-in tokens (so you stay logged in) and your list of ignored users (which never leaves your device). Logging out removes the tokens.

Deletion and retention

  • Deleting a message hides it, but does not erase it. A deleted message disappears for everyone in the app, and its record is retained in the database marked as deleted. Assume an administrator can still recover it.
  • Uploaded files are not deleted when the message containing them is removed. The file stays on the server and its link keeps working.
  • Account information is kept until the operator removes it. Ask the administrator if you want your account and content deleted.

How your data is protected

Passwords are hashed with Argon2. Connections use HTTPS. Sign-in attempts are rate-limited, uploads are restricted by file type and served with headers that stop the browser from treating them as code, and every message is escaped when displayed so it cannot run scripts. No system is perfectly secure, and this one is maintained by a small operator — please keep that in mind when deciding what to share.
